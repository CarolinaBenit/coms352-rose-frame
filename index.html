Rose Frame

A gentle picture of a stack buffer overflow. Type a name, and watch an unbounded copy walk from a small buffer toward the saved return address.

1. The call saves a way back

Calling greet stores a return address and the caller’s frame pointer beside the new locals.

2. The buffer sits just below

On this teaching frame the stack grows down, so buf[0] is the lowest address in the picture.

3. The copy walks upward

strcpy writes toward higher addresses and does not stop at the end of the array.
